# 主角卡 · 锅巴

> 赛事要求：**1 张主角卡** —— 一句话或草图、生成的角色、游戏里的样子。
> 最终导出为一张竖版图片提交（见 §5）。

## 1. 一句话

> 一个来讨伐魔王的近战剑士。他每杀一只魔物就更强一点，五分钟后要么死在魔王殿，要么坐上王座。

## 2. 已确定的设定

| 项 | 内容 |
| --- | --- |
| 名字 | 锅巴（名字 / 绰号，不是食物造型） |
| 身份 | 来讨伐魔王的勇者 |
| 职业 | **近战剑士**（单手剑），招牌远程技是**剑气**（直线穿透） |
| 行为 | 自动索敌、追击、近战、用技能、升级变强 |
| 与魔王 | 完全无视魔王（他只砍魔物） |
| 美术风格 | **半写实暗黑**（日式 RPG 质感，参照《勇者斗恶龙》的年代感氛围） |
| 动画方案 | **单张静态贴图 + 程序化摇摆**（不用精灵图，见 §4） |

**仍是可调整的**：铠甲细节、配色、面部（是否有疤、发型、年龄感）。

## 4. 动画方案：贴图 + 摇摆（强制约定）

**不做精灵图。** 原因：AI 出多帧的一致性极差（同一角色 8 帧会长成 8 个人），而俯视角小尺寸下剪影摇摆已经足够。

| 动作 | 做法 |
| --- | --- |
| 待机 | 呼吸缩放 + 极轻微上下浮动 |
| 移动 | **左右摇摆**（±7°，周期 ≈0.42s）+ 上下浮动 2.5px |
| 攻击 | 前倾蓄力 → 前冲 10px + 前倾 12° → 回弹 |
| 受击 | 白闪 60ms + 抖动 |
| 施法（剑气） | 剑身自下而上亮起 → 前刺 → 刀光飞出 |
| 死亡 | 倾倒 90° + 压扁 + 淡出 |

> 一张贴图 = 一个角色。资产量降到 1/9，一致性风险接近 0，且风格统一（全游戏共用一套摇摆曲线，只调幅度与频率）。
