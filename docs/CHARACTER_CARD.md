# 主角卡 · 锅巴（Guoba）

> 赛事要求：**1 张主角卡** —— 一句话或草图、生成的角色、游戏里的样子。
> 本文件是这张卡的底稿与素材台账；最终导出为一张竖版图片提交（见 §5）。

⚠️ **重要**：锅巴是**名字 / 绰号**，不是一块锅巴（食物）。他是一个**人**——瘦勇者，背一口铁锅当盾。
"锅巴"来自三年前被龙焰烧过没死、脸上留下龟裂焦疤。

---

## 1. 一句话

> 一个瘦得不像话的勇者，背着口凹了边的铁锅当盾，脸上有一片烧疤——魔物都叫他「锅巴」，因为这人又硬又难啃。

| Ⅲ 焚身（Lv10+） | 全身皮肤龟裂透出熔岩光、铁锅裂成三瓣仍在用、头发像余烬、脚下拖出火星 |

## 3. 角色设定

| 项 | 内容 |
| --- | --- |
| 名字 | 锅巴（绰号；本名无人记得） |
| 身份 | 第 302 个来讨伐魔王的勇者 |
| 性格 | 沉默、倔、不知道自己该怕 |
| 体型 | 偏瘦，比标准勇者矮半头——**反差来自"他看起来打不过任何人"** |
| 记忆点 | 那口铁锅。挡刀用它，坐用它，最后也是它先碎 |
| 声音 | 铁锅被敲的闷响、粗喘、短促怒吼 |

**台词表**

| 时机 | 台词 |
| --- | --- |
| 登场 | 「……第几个了？」 |
| 升级（Lv2–4） | 「还能砍。」 |
| 升级（Lv5–9） | 「锅里还有火。」 |
| 升级（Lv10+） | 「我烧起来了。」 |
| 受伤 | 闷哼 + 铁锅撞击声 |
| 血量低 | 「……不够硬。」 |
| 进化到 Lv15（失败线） | 「现在，我是魔王。」 |
| 被击败 | 铁锅碎裂声 → 长静默 |
