## 怎么用这个文件

**开工前**（30 秒）：
```powershell
git fetch origin
git log --oneline HEAD..origin/main     # 看有没有新提交
# 读本文件，确认没人占你要改的文件
```

**收工后**（1 分钟）：
1. 在上面的「文件占用表」把自己那行改掉
2. 在「交接记录」顶部加一条：做了什么 / 验证了什么 / 发现什么 / 请求什么
3. commit 时把本文件一起提交

**冲突熔断**：如果 `git fetch` 后发现你要改的文件刚被别人改过，**停手**，
在交接记录里写清楚，等用户协调。不要整文件覆盖。
