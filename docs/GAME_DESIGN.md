# 《锅巴必须死》完整策划案

> **一句话**：你是深渊，你把怪物摆上去喂给来讨伐你的小勇者「锅巴」——他吃得越肥，杀死他时你拿的分越高，但你也可能被他反杀。
>
> **Reverse Roguelike · 反向肉鸽 · 2D 俯视角 · 单局 6 分钟 · 浏览器直接玩**

- 版本：v1.0（首版可实施稿）

- 交付要求对照：浏览器可玩链接 / 完整一局（开始→结算→重开）/ 操作提示在游戏内 / 主角卡 1 张

## 1. 设计目标

### 1.1 一句话定位

**《吸血鬼幸存者》的画面感 + 《土豆兄弟》的构筑节奏 + 立场完全倒转的一次实验。**

经典肉鸽：你是那个越杀越强的幸存者，怪物是刷出来的饲料。
本作：**怪物是你摆上去的，越强的是对面那个勇者，你是那个该死的深渊。**

### 1.2 玩家实际在玩什么

| 玩家以为自己在玩 | 实际上在玩 |
| --- | --- |
| 摆怪打勇者 | **养蛊**：控制「喂多少」 |
| 攒钱升级 | 在「让他变强换高分」与「别让他强到杀不死」之间走钢丝 |
| 塔防 | 反向塔防：塔是我方的、兵是对面的、还会打野升级 |

### 1.3 三条必须成立的设计支柱

1. **反向**：变强的是敌人，玩家的工作是「管理敌人的成长曲线」。一旦做成普通塔防就是失败。
2. **可读**：锅巴每一次变强都必须**肉眼可见**（变大、变色、学会新招、播报）。
3. **再来一局**：结算必须留下一个「如果我刚才少喂两口」的念头。

### 1.4 情绪曲线（一局 6 分钟）

```
紧张度
  │                                        ╭──╮  决战：他狂暴 / 你梭哈
  │                            ╭───────────╯  ╰╮
  │              ╭─────────────╯               ╰──╮ 险胜或翻车
  │   ╭──────────╯  爽：他越吃越肥，我分越高
  │  ╭╯ 教学：哦，怪物是喂他的
  └──╯──────────────────────────────────────────────▶ 时间 0→6:00
     0:00   1:00    2:30      4:00      5:00    6:00
     学规则  养肥期   博弈期     压血线    崩坏期   结算
```

| --- | --- |

## 2. 世界观与角色

### 2.1 设定

深渊第七层，一群饿了一千年的怪物终于等来了一个勇者。

……然后发现这个勇者是一块锅巴。

深渊领主（玩家）决定不杀他，先养着——**锅巴吃得越多，身上结的焦壳越厚，敲碎的时候越值钱。**

### 2.2 主角档案：锅巴（Guoba）

| 项 | 内容 |
| --- | --- |
| 身份 | 被烤过头的米饭锅巴，自认为是天选勇者 |
| 外形 | 方形焦黄脆片身体，边缘酥裂，撒着黑芝麻，两条小短腿，一对圆眼睛，披着讨伐深渊的破布斗篷，手持小木剑 |
| 体型变化 | 每 3 级变大一圈（缩放 1.0 → 1.45），焦壳从金黄 → 深棕 → 焦黑 → 鎏金 |
| 声音 | 走路"咔嚓咔嚓"、受击"咔！"、升级"咔嚓——！！" |
| 口头禅 | Lv1「深渊！我来啦！」/ Lv5「我还能再吃一口！」/ Lv10「我……有点撑……」/ Lv13「我即是焦！」 |
| 记忆点 | **他越大只，越难打死，也越值钱**。玩家会亲手下厨把他烤到最强，再砸碎他 |

### 2.3 三个形态（对应三个阶段）

| 阶段 | 等级 | 形态 | 视觉 |
| --- | --- | --- | --- |
| Ⅰ 酥脆期 | Lv1–4 | 金黄锅巴 | 明亮、圆润、斗篷完好 |
| Ⅱ 焦壳期 | Lv5–9 | 深棕锅巴 | 焦痕、斗篷破损、眼睛发红、身上冒烟 |
| Ⅲ 铁锅期 | Lv10+ | 焦黑/鎏金锅巴 | 裂纹透出熔岩金光、斗篷烧毁、拖出火星粒子 |

## 3. 核心循环

### 3.1 30 秒节拍（玩家每次决策的周期）

```
① 看：锅巴在哪、血多少、场上还剩几星
② 选：从 4–6 张手牌里挑一张（费用 / 星级 / 位置）
③ 放：拖到场上，怪物自动开始攻击
④ 收：锅巴吃掉怪物 → 升级 → 播报「锅巴学会了 旋风斩」→ 他更强了
⑤ 判：继续喂？还是先献祭止损？
   └─ 每 25 秒 / 锅巴每升 3 级 → 弹「育种强化」3 选 1（你的成长回合）
```

### 3.2 一局 6 分钟的三幕结构

| 幕 | 时间 | 主题 | 玩家该有的感受 |
| --- | --- | --- | --- |
| 第一幕 养肥 | 0:00–2:00 | 学习 + 第一次"我把他喂大了" | "诶？他变大了" |
| 第二幕 博弈 | 2:00–4:00 | 星数上限放开，卡牌升星，锅巴学会大招 | "再喂会不会翻车" |
| 第三幕 崩坏 | 4:00–6:00 | 锅巴血线低 → 进入狂暴/逃跑；玩家梭哈 | "快！快！快！" |

### 3.3 胜负条件

- **胜利**：6:00 之前把锅巴 HP 打到 0。
- **失败**：6:00 到时锅巴仍存活（"他打了个饱嗝，扬长而去"）。
- **特殊失败**：锅巴升到 Lv 15（"他吃成了深渊本身"）→ 立刻结束，判定"被反噬"。

> 失败不是惩罚，是钩子：结算面板会明确告诉你差多少（"再打 87 点伤害就赢了"）。

## 4. 玩法系统

### 4.1 场地与视角

- 2D 俯视角（45° 倾斜的平面感），单屏竞技场，不滚动。
- 场地：**深渊祭坛**，圆形石台（直径 ≈ 900 设计像素），外圈是虚空，边缘有熔岩/魂火。
- 场地分 3 个环带（视觉提示，无机制）：
  - 内环（半径 0–140）：**核心裂隙**，怪物在此有 +10% 攻速（"守着家门口"）
  - 中环：常规战场
  - 外环：怪物移速 +15%（"绕后"）
- 锅巴从场地边缘的"入口"登场，全程在场地内活动。

### 4.2 资源：魂

| 项 | 数值 |
| --- | --- |
| 名称 | 魂（Soul） |
| 初始 | 20 |
| 上限 | 100（强化可到 160） |
| 回复 | 8 / 秒（强化可到 22 / 秒） |
| 额外来源 | 怪物死亡返还 50% 费用；献祭返还 60% |
| UI | 场地下方的发光魂条 + 数字 |

**设计意图**：魂是"手速"资源。回复速度决定了"你能多快把饲料送上去"，是所有强化的第一优先级争夺点。

### 4.3 星级预算（本作最核心的约束）

> 场上所有存活怪物的**星级总和**不能超过上限 `X(t)`。

| 项 | 规则 |
| --- | --- |
| 基础曲线 | `X(t) = 3 + floor(t / 30)`，t 单位为秒，基础封顶 15 |
| 强化上限 | 「星域扩张」每层 +2，最多 +6（理论峰值 21） |
| 表现 | 场地外圈一圈星点，亮起的数量 = 当前预算占用 |
| 超限时 | 卡片变灰 + 提示"星域已满"；新怪无法放下（已放的不受影响） |

**为什么用星级而不是数量上限**：让玩家在"很多弱怪"和"一只强怪"之间做真实选择，而两者对锅巴的意义完全不同（弱怪 = 快速经验饲料；强怪 = 高价值目标 + 更长的拖延时间）。

`X(t)` 示例：0s→3，1:00→5，2:00→7，3:00→9，4:00→11，5:00→13，6:00→15。

### 4.4 怪物卡

#### 4.4.1 卡牌结构

每张卡 = 一个**族**（种族）× 一个**星级**。星级决定数值倍率、费用与是否解锁专属技能。

| ★ | 8 | ×1.0 | ×1.0 | — | 20 |
| ★★ | 18 | ×2.3 | ×2.2 | 族被动增强 | 45 |
| ★★★ | 32 | ×5.2 | ×5.0 | **觉醒技能** | 100 |

> 首发手牌：1 / 3 / 5 / 7（四张 ★ 卡）。★★ / ★★★ 通过局内「育种强化 · 升星」获得，营造"我的手牌在长大"的成长感。

#### 4.4.3 手牌与卡池

- 手牌位：4（可强化到 6）。开局固定 4 张 ★ 卡。
- 卡牌升星：育种强化里抽到该族卡 → 该卡永久升 1 星（局内，跨局不保留）。
- 手牌满时抽到新族卡 → 替换最弱一张（或按玩家选择）。
- 所有卡牌**无冷却**，唯一限制是魂和星级预算。

#### 4.4.4 献祭（关键的"止损"操作）

| 项 | 内容 |
| --- | --- |
| 触发 | 双击场上怪物 / 长按 0.4 秒 / 右键 |
| 效果 | 立刻引爆：对半径 110 内敌人造成 `星级 × 28` 伤害；返还 60% 费用 |
| 代价 | **不给锅巴经验**（这是重点——你在饿他） |
| 冷却 | 无，但每献祭一次，锅巴获得 1 层「饥饿」（攻速 +4%，最多 10 层） |
| 教学 | 第一次出现"锅巴快升级了"时弹出提示："献祭能饿住他，但会让他更饿" |

**设计意图**：给玩家一个"反喂"手段，让"喂多少"变成真正的策略，而不是被动挨打。

### 4.5 锅巴：AI 勇者

#### 4.5.1 基础属性

| 属性 | 初始 | 每级成长 | 说明 |
| --- | --- | --- | --- |
| HP | 620 | +58 | 血条在屏幕顶部 + 头顶双显示 |
| 攻击 | 22 | +6.5 | 每次挥砍 |
| 攻速 | 1.1 次/秒 | +0.018 | |
| 移速 | 108 px/s | +2.2（上限 +44） | |
| 护甲 | 0 | — | 只来自强化 |
| 暴击率 | 5% | — | 只来自强化 |

#### 4.5.2 经验与等级

- 经验来源：击杀玩家怪物（★=20，★★=45，★★★=100）。
- 升级需求：`XP_need(L → L+1) = 50 + 35 × (L − 1)`
  - Lv1→2：50　Lv2→3：85　Lv5→6：190　Lv10→11：365
- 累计到 Lv10 约 1710 经验 ≈ 击杀 85 只 ★ 怪。
- **每升 1 级必得 1 条强化**（从池中按权重随机，玩家可见播报）。
- 每 3 级额外获得 1 条「标志性强化」（必定是强力、视觉化的，例如旋风斩 / 冲锋 / 烈焰）。

#### 4.5.3 AI 状态机

```
        ┌──────────── 复活/初始 ────────────┐
        ▼                                   │
   ┌─────────┐  有怪在射程   ┌──────────┐   │
   │  SEEK   │──────────────▶│  ATTACK  │   │
   │ 追最近怪 │◀──────────────│ 挥砍/技能 │   │
   └─────────┘   目标死亡     └──────────┘   │
     │  │                          │        │
     │  │ 血<25% 且 有治疗次数      │        │
     │  ▼                          │        │
     │ ┌─────────┐  回复到 60%     │        │
     │ │ RETREAT │─────────────────┘        │
     │ └─────────┘                          │
     │ 血<20% 且 处于第三幕                 │
     ▼                                      │
   ┌─────────┐  血回到 45% 以上             │
   │ ENRAGE  │──────────────────────────────┘
   │ 狂暴：伤害 |
   │ +60%，移速 |
   │ +40%，无退 │
   └─────────┘
```

- **目标选择**：默认"最近的怪物"；若存在「嘲讽」状态的怪物则优先；若 3 秒内无目标，则朝场地中心移动（"找路"）。
- **技能释放**：技能有独立 CD，AI 按"目标数量 / 血量 / 距离"打分决定释放时机（不追求最优，追求**好看且公平**）。
- **公平性**：AI 不做"读指令"级躲避；玩家永远能通过位置与卡组控制节奏。

### 4.6 玩家：育种强化

#### 4.6.1 触发节奏

- 每 **25 秒** 触发一次（0:25 / 0:50 / … / 5:50，共 14 次）。
- 锅巴每升 **3 级** 额外触发一次。
- 触发时**短暂减速世界到 0.15 倍速**（不是暂停，保留紧张感），弹出 3 选 1 卡片。

#### 4.6.2 强化池（首版 32 条，分 4 类）

| 厚壳 | 全怪物生命 +18% | 5 |
| 躁动 | 全怪物攻速 +10% | 4 |
| 疾行 | 全怪物移速 +9% | 3 |
| 魂涌 | 魂回复 +2.5/秒 | 5 |
| 魂池 | 魂上限 +30 | 3 |
| 回收 | 怪物死亡返还 +18% | 3 |
| 血税 | 怪物造成的伤害 6% 转为你的魂 | 3 |


## 6. 表现设计

> 这一节是"看起来不像学生作业"的关键。技术落地见 `TECH_STACK.md` §4。

### 6.1 美术风格

**风格锚点**：`手绘卡通 + 深渊霓虹`。

- 造型：粗描边（3–4px 深色描边）、圆润轮廓、高饱和主体色、低饱和背景。
- 光照：顶光 + 一点边缘光（rim light），主体永远比背景亮 30%。
- 反差萌：可爱的锅巴 vs 阴森的祭坛，情绪张力来自美术对比。
- 调色板（**全局唯一调色板，所有 AI 生图都锁它**）：

| 用途 | 色值 |
| --- | --- |
| 深渊底色 | `#0B0A14` `#151226` |
| 祭坛石 | `#2E2740` `#43395C` |
| 魂光（玩家） | `#5FF2D0` `#2ED9B4` |
| 熔岩/危险 | `#FF6B4A` `#FFB347` |
| 锅巴金脆 | `#F5C24B` `#FFE39A` |
| 焦黑 | `#4A3427` `#241A14` |
| 血/伤害 | `#FF3B5C` |
| 治疗/毒 | `#7BE05F` `#9B6BFF` |

### 6.2 资产清单（AI 生成）

| 类别 | 数量 | 尺寸 | 生成方式 |
| --- | --- | --- | --- |
| 锅巴 3 形态 × 4 动作（待机/走/攻击/受击） | 12 组 | 512×512 | 图像模型 + 一致性参考图 |
| 小怪 4 族 × 3 星（外观差异靠配件/颜色） | 9 张 | 384×384 | 同上 |
| 场地祭坛（多层：地面/边缘/装饰） | 3 层 | 1536×1536 | 图像模型，正俯视 |
| UI 图标（魂、星、剑、盾、心、时钟…） | 18 个 | 128×128 | 批量生成 + 切图 |
| 卡面背景 / 强化卡框 | 6 张 | 512×768 | 生成 + CSS 叠字 |
| 特效贴图（光斑、火星、烟、血、骨片、冲击环） | 10 张 | 256×256 | 生成或程序化 |
| 标题主视觉 / 主角卡立绘 | 3 张 | 1536×1024 | 高质量一次出图 |
| BGM（标题 / 战斗 base / 战斗 高危 / 结算） | 4 首 | 60–90s 循环 | 音乐模型 |
| 音效（放置/命中/死亡/升级/献祭/UI/锅巴台词） | 25 个 | <2s | 程序化合成 + 少量生成 |
| 过场短片（可选） | 1 个 | 4–6s | 视频模型 → 转 WebM/MP4 |

**一致性策略**（AI 生图最大的坑）：
1. 先出 1 张「风格锚点图」，之后每次生成都把它作为参考图（image-to-image / 参考图模式）。
2. 固定 prompt 模板：`[主体描述], 手绘卡通风格, 粗描边, 顶光, 纯色背景 (#0B0A14), 游戏素材, 无文字, 无阴影投到地面`。
3. 所有产物统一走 `tools/art-pipeline` 后处理：去背景 → 裁边 → 统一缩放 → 生成缩略图 → 打包图集。
4. **人工/模型二次筛选**：批量出 4 张选 1，淘汰率保持在 75%。

### 6.4 动效

- **弹性曲线**：所有 UI 出入场用 `back.out(1.6)`；数值变化用数字滚动（Ticker 插值）。
- **卡牌手感**：悬停抬起 8px + 3D 倾斜（`rotateX/rotateY` 跟随鼠标）+ 边框发光；选中时卡片飞行到光标、半透明预览落点。
- **锅巴变形**：升级时用 3 帧 squash & stretch（1.0 → 1.12宽/0.9高 → 1.0），配合缩放递增。
- **血条**：延迟条（白色缓慢跟随）+ 主条，参考《吸血鬼幸存者》。
- **强化 3 选 1**：三张卡从底部错峰飞入（0 / 60 / 120ms），悬停时其他两张变暗并缩小 4%。

## 7. 技术实现要点（摘要）

完整选型见 `docs/TECH_STACK.md`。

- **栈**：TypeScript + Vite + PixiJS 8，纯 2D，无 3D。
- **架构分层**：`core`（循环/事件/随机） → `ecs`（实体） → `gameplay`（战斗/卡牌/强化/AI） → `render`（渲染/粒子/镜头） → `ui`（DOM） → `app`（装配）。
- **确定性模拟**：所有随机走种子化 PRNG（`mulberry32`），使"每日深渊"与回放/模拟脚本可复现。
- **无渲染模拟**：`tools/simulate.mjs` 直接跑 `gameplay` 层 1000 局，用于 5.1 的数值校准（这也是我们能在 24 小时内调平衡的唯一手段）。
- **性能预算**：实体 ≤ 400，粒子 ≤ 600，Draw call ≤ 120，首屏资源 ≤ 3MB。
