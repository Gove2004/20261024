## 0. 定位

### 0.1 一句话定位

**《吸血鬼幸存者》的画面感 + 《土豆兄弟》的构筑节奏 + 立场倒转。**

常规肉鸽里，你是那个越杀越强的幸存者，怪物是刷出来的。
本作里，**魔物是你放的，越打越强的是对面那个勇者，你是坐在王座上的魔王**。

### 0.2 玩家在做什么

一句话：**一边变强，一边别让对方变强，然后在时间耗尽前杀掉他。**

| 玩家 | 勇者 |
| --- | --- |
| 魔魂随时间回复，放魔物 | 杀你的魔物获得魔气，升级、随机强化 |
| 星级上限随时间提高 | 属性随等级成长 |
| 每 25 秒 3 选 1「魔王权能」 | 每升 1 级得 1 条强化 |
| 目标：5 分钟内把他打死 | 目标：撑到 5 分钟，或把你砍死 |

**双方都在成长，比的是谁长得更快。** 这就是全部。

### 0.4 设计支柱

1. **反向**：成长曲线属于敌人，玩家的核心操作是"控制战斗节奏"。
2. **可读**：勇者变强必须肉眼可见（外形变化 + 播报），玩家要知道自己在跟什么打。
3. **再来一局**：结算告诉你怎么死得更快、死得更少。

## 2. 核心循环

### 2.1 25 秒节拍

```
① 看：勇者血量、位置、他快升级了没有、我还剩几星/多少魔魂
② 放：挑一张卡，拖到大厅
③ 打：魔物自动攻击；勇者反击、清怪
④ 变：他杀掉的每一只魔物都变成他的魔气 → 他升级、变强、播报
⑤ 选：每 25 秒 / 他每升 3 级 → 你 3 选 1「魔王权能」
⑥ 判：这帮魔物在赚钱还是在送经验？要不要引爆？
```

**核心权衡**：魔物既是你的输出，也是他的经验。放多少、放什么、放在哪，全部围绕这一条。

### 2.2 三幕

| 幕 | 时间 | 双方状态 | 玩家感受 |
| --- | --- | --- | --- |
| Ⅰ 发育 | 0:00–1:40 | 他弱、你手牌弱 | "能打，但打不死" |
| Ⅱ 对抗 | 1:40–3:20 | 他学会技能、你拿到核心权能 | "他开始难杀了" |
| Ⅲ 决战 | 3:20–5:00 | 他狂化、你梭哈 | "时间不够了" |

### 2.3 胜负

- **胜利**：5:00 前把他打死。
- **失败**：5:00 时他仍存活。
- **特殊失败**：他升到 Lv15（成长失控）→ 立即结束。
- 结算明确写清差距（"再造成 87 点伤害就赢了" / "快 20 秒就能进 A 级"）。

## 3. 玩法系统

### 3.1 场地

- 2D 俯视，单屏不滚动。
- **魔王殿**：圆形大厅（直径 ≈ 900 设计像素），中央王座台，外圈熔岩沟。
- 三个环带（有轻机制）：内环「王座台前」魔物攻速 +10% / 中环常规 / 外环魔物移速 +15%。
- 勇者从大厅下方入口进场。

### 3.2 资源：魔魂

| 项 | 数值 |
| --- | --- |
| 初始 / 上限 | 20 / 100（权能可到 160） |
| 回复 | 8 / 秒（权能可到 22 / 秒） |
| 回收 | 魔物死亡返还 50% 费用；引爆返还 60% |

### 3.3 星级上限（核心约束）

场上存活魔物的**星级总和** ≤ `X(t)`。

| 项 | 规则 |
| --- | --- |
| 曲线 | `X(t) = min(3 + floor(t / 25), 15)`，t 为秒 |
| 权能加成 | 「星数上限」每层 +2，最多 +6 |
| 表现 | 大厅外圈星点阵列，亮起数量 = 已占用 |
| 超限 | 卡片变灰 + 提示"星数已满" |

示例：0s→3，1:00→5，2:00→7，3:00→10，4:00→12，5:00→15。

- 手牌位 4（权能可到 6），无冷却，唯一限制是魔魂与星数上限。

#### 3.4.4 引爆（自毁回收）

#### 3.5.2 成长

- 魔气来源：击杀 ★ / ★★ / ★★★ 魔物 → 20 / 45 / 100。

- 每级 1 条随机强化；每 3 级 1 条必出的强力强化（播报可见）。
- 累计到 Lv10 约 1710 魔气。

#### 3.5.3 状态机

```
   SEEK ──有目标──▶ ATTACK ──目标死亡──▶ SEEK
     │                                     │
     │ 血<25% 且还有治疗                    │
     ▼                                     │
  RETREAT ──回到 60%───────────────────────┘
     │
     │ 血<20% 且第三幕
     ▼
  ENRAGE：伤害 +60%、移速 +40%、不再后退
```

- 目标选择：最近魔物；有嘲讽优先。

### 3.8 计分与评级

> **不计"勇者等级"，只计快、狠、稳。** 放他长大没有任何分数收益。

```
速度分  = 剩余秒数 × 12                 // 3:00 击杀（剩 120s）= 1440
规模分  = 峰值星数 × 50 + 遗物数 × 100    // 12 星 + 3 遗物 = 900
损失分  = −(被他击杀的魔物数 × 6)         // 死 50 只 = −300
总分    = 速度分 + 规模分 + 损失分
```

| 评级 | 分数 |
| --- | --- |
| S | ≥ 1300 |
| A | ≥ 1000 |
| B | ≥ 700 |
| C | < 700 |
| 失败 | — |

### 4.3 公式

```
星数上限   X(t) = min(3 + floor(t/25), 15) + 2 × 层数
升级经验   XP_need(L) = 50 + 35 × (L − 1)
勇者 HP    HP(L) = 520 + 55 × (L − 1)
勇者攻击   ATK(L) = 20 + 6.0 × (L − 1)
勇者移速   SPD(L) = min(108 + 2.2 × (L − 1), 152)
魔物费用   cost = [0, 8, 18, 32][star]
死亡返还   refund = cost × (0.5 + 0.18 × 层数)
引爆伤害   dmg = star × 28 × (1 + 0.8 × [引爆强化])
```

### 5.4 动效与镜头

- UI 出入场 `back.out(1.6)`；数值滚动插值；卡牌悬停抬起 + 3D 倾斜。
- 血条双层（延迟白条 + 主条）。
- 镜头：跟随勇者与场地中心加权中点；震动 2–8px；zoom punch 1.0→1.06→1.0（180ms）；命中 hitstop 2–4 帧。
- 开局镜头 1.6→1.0（1.2s）；击杀时推进 1.0→1.25（0.8s）+ 时间放慢。

### 5.6 音频：全程序生成

> 不加载任何音频文件，全部 WebAudio 合成（详见 `docs/TECH_STACK.md` §5）。

- BGM：步进音序器，120 BPM，D 弗里吉亚，i–♭VI–♭III–♭VII 循环；drone / bass / pad / 鼓 / 旋律 五层按阶段淡入。
- 危机层：他 HP <30% 时叠心跳 + 低通开到 18kHz。
- 音效：25 个合成配方（命中=噪声+带通+随机音高；金属撞击=三角波+泛音）。
- 总线：Master → 压缩器；BGM / SFX / UI 三条；命中时对 BGM 侧链 −3dB。
- 同时发声 ≤40；首次 pointerdown 解锁 AudioContext。

## 6. 技术要点（摘要）

- TypeScript + Vite + PixiJS 8，纯 2D。
- 分层：`core` → `ecs` → `gameplay` → `render` → `ui` → `app`，单向依赖。
- 种子化 PRNG，支持每日挑战与无渲染模拟（`tools/simulate.mjs` 跑 1000 局校准 §4.2）。
- 预算：实体 ≤400，粒子 ≤600，Draw call ≤120，首屏 ≤3MB。
