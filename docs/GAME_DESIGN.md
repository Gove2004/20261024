## 0. 定位

### 0.1 一句话

**《吸血鬼幸存者》的场地感 + 《暗黑地牢》的氛围 + 立场倒转：变强的是对面那个勇者。**

常规肉鸽里你是越杀越强的幸存者；这里你是那个**被讨伐的魔王**，只能放怪，不能动手。

### 0.2 一局是什么样

```
开局  魔王站在王座前，勇者锅巴从大厅入口走进来
0:00  你放出第一只史莱姆，它冲向勇者
0:06  勇者两刀砍碎史莱姆，身上亮了一下：锅巴 Lv2，学会了「剑气斩」
0:30  星数上限 +1，你 3 选 1 拿到「冷却缩减」
1:20  你切到侧翼放下毒蜘蛛，勇者转身追它，距离被拉开
2:40  他放了一道剑气，把你三只怪串在一条线上打掉半血
4:10  他只剩 180 血，狂化了，攻速明显加快
4:38  石魔像嘲讽拉住他，四只怪围上 —— 他倒下
      结算：用时 4:38，S 级
```

### 0.3 三方关系（必须记住的一张表）

| 角色 | 能做什么 | 不能做什么 |
| --- | --- | --- |
| **魔王（玩家）** | 移动（看视野）、召唤魔物、引爆魔物、选权能 | **不能攻击**、不会被打、不会死 |
| **勇者（AI）** | 移动、近战、剑气远程、按等级用技能、升级变强 | 不会攻击魔王 |
| **魔物（玩家投放）** | 自动索敌、攻击勇者、提供控制/治疗/召唤 | 不需要操作 |

**胜负只由时间与勇者血量决定**：5:00 前把他打死 = 胜利；没打死 = 失败。

### 0.4 设计支柱

1. **反向**：成长曲线属于敌人。玩家的核心操作是"控制他在哪、他打谁、他什么时候能打到"。
2. **可读**：勇者每一次变强都要看得见（外观 + 播报 + 新技能第一时间展示）。
3. **AI 是本作的手感**：勇者不是木桩，也不是外挂。他打得像个人 —— 会追击、会撤退、会绕后、会连招，但所有动作都有前摇，玩家能读、能应对。

## 1. 世界与角色

### 1.1 场地：魔王殿大厅（大于单屏）

| 项 | 数值/说明 |
| --- | --- |
| 世界尺寸 | **2400 × 1600**（设计像素） |
| 视口 | 1280 × 720（16:9），letterbox 适配 |
| 相机 | **锁定魔王本体**，平滑跟随（lerp 0.12），出界夹取 |
| 地形 | 中央王座台（不可通行圆形障碍，半径 180）、四周石柱（可绕行）、外圈熔岩沟（不可通行） |
| 战斗区域 | 王座台以外的大厅环形区域，直径约 1500 |
| 屏外提示 | 勇者离屏时，屏幕边缘显示方向箭头 + 距离 + 迷你血条 |

> **为什么大于单屏**：拉开距离就成了资源。魔王可以退到安全处布阵，勇者会追着魔物跑——"在哪打"变成玩家能操作的变量。

### 1.2 魔王（玩家）

| 项 | 内容 |
| --- | --- |
| 定位 | **手无缚鸡之力**。不能攻击，不会被打，不会被任何东西阻挡（漂浮） |
| 移动 | WASD / 方向键 / 触屏虚拟摇杆，速度 260 px/s |
| 存在意义 | ① 决定镜头看哪 —— 即"你看向哪片战场"；② 决定**召唤范围** |
| 召唤范围 | 以魔王为圆心、半径 **520** 的圆，超出范围的落点无效（半透明红圈提示） |
| 外观 | 深色斗篷 + 悬浮（不做精细动画，只是"存在"） |
| 死亡 | 无。魔王不死 |

**设计要点**：魔王只有视野与投放权，没有战斗力——所以玩家的注意力全在"放什么、放哪、什么时候放"，这正是反向肉鸽该有的心态。

### 1.3 勇者：锅巴

| 项 | 内容 |
| --- | --- |
| 定位 | **近战剑士**，招牌远程技是**剑气**（直线穿透，见 §5.5） |
| 外观方向 | 半写实暗黑（参照《勇者斗恶龙》质感的日式 RPG）：破旧皮甲 + 单手剑，体量比魔物高一档 |
| 行为 | 自动索敌、追击、攻击、撤退、放技能、升级变强 |
| 与魔王 | **完全无视**（叙事上：他只认魔物挡路，魔王是最后一道菜） |
| 阶段 | Ⅰ Lv1–4 / Ⅱ Lv5–9 / Ⅲ Lv10+（外观差异见 §8.3） |

## 2. 核心循环

### 2.1 30 秒节拍（一局 10 拍）

| 拍 | 时间 | 系统动作 | 玩家动作 |
| --- | --- | --- | --- |
| 1 | 0:00–0:30 | 星数上限 4→? 、教学 | 学会放置，看到勇者第一次升级 |
| 2 | 0:30 | **权能 3 选 1**、星数上限 +2 | 选第一个构筑方向 |
| 3 | 1:00 | 勇者 Lv3–4，开始用技能 | 开始分批投放，避免被一剑串三只 |
| 4 | 1:30 | 权能；场上星数吃紧 | 体会"卡 CD"的压力 |
| 5 | 2:00 | 勇者 Lv5 → **进入阶段Ⅱ** | 感觉到他变强了 |
| 6 | 2:30 | 权能；解锁 ★★★ 卡 | 第一次放出石魔像 |
| 7 | 3:00 | 勇者 Lv7 | 中盘博弈 |
| 8 | 3:30 | 权能；勇者 Lv8 | 构筑成型 |
| 9 | 4:00 | 勇者 Lv9–10 → **阶段Ⅲ** | 进入决战节奏 |
| 10 | 4:30 | 最后一拍，星数接近封顶 | 梭哈 |

> 每个 30 秒 = 一次"看局势 → 选权能 → 调整投放"的完整回合。**玩家的操作频率天然被权能拉扯成 30 秒一次深呼吸。**

### 2.2 逐帧循环

```
① 移动魔王（看战场、换召唤点）
② 点卡 → 点地放置（受 CD + 星数上限 + 召唤范围三重约束）
③ 魔物自动索敌；勇者索敌、走位、攻击、放技能
④ 勇者杀掉魔物 → 获得魔气 → 升级 → 得到技能 → 越强
⑤ 每 30 秒：权能 3 选 1（世界减速到 0.15）
⑥ 5:00 或勇者血空 → 结算
```

### 2.3 胜负

| 条件 | 结果 |
| --- | --- |
| 5:00 前勇者 HP = 0 | **胜利** |
| 5:00 时勇者存活 | **失败** |
| 勇者升至 Lv15 | **失败**（成长失控，立即结束） |

## 3. 玩家系统

### 3.1 资源：没有资源

**取消魔魂。** 玩家没有任何货币。

限制玩家的只有三条：

1. **每张卡的独立放置 CD**（节奏）
2. **场上星数上限 `X(t)`**（规模）
3. **召唤范围 ≤520px**（位置）

> 设计意图：没有经济就没有"攒钱憋大件"的躺平玩法，所有决策都变成**即时取舍**。卡片 CD 让手牌本身成为节奏器。

### 3.2 卡片 CD

| 星级 | 基础 CD | 说明 |
| --- | --- | --- |
| ★ | 4–7 s | 填充、骚扰 |
| ★★ | 9–13 s | 主力 |
| ★★★ | 18–22 s | 决战手段 |

- CD 从**放置成功**开始计算，按该卡独立计时。
- 权能「冷却缩减」每层 −8%，最多 5 层（−40%，乘算）。
- 回合开始时全部 CD 就绪。
- UI：卡面环形进度 + 剩余秒数；就绪时轻微呼吸发光。

### 3.3 星数上限

| 项 | 规则 |
| --- | --- |
| 曲线 | `X(t) = 4 + 2 × floor(t / 30)`，t 秒；基础封顶 **24** |
| 权能加成 | 「星数上限」每层 +2，最多 +6（峰值 30） |
| 占用 | ★=1 星，★★=2 星，★★★=3 星 |
| 超限 | 卡片变灰 + 提示"星数已满"，不能放新卡（已在场的强制保留） |
| 表现 | 屏幕左下星点阵列；接近上限时变红 |

示例：0:00→4，1:00→8，2:00→12，3:00→16，4:00→20，5:00→24。

### 3.4 引爆（非核心，但有分量）

| 项 | 内容 |
| --- | --- |
| 触发 | 双击魔物 / 长按 0.4s / 右键 |
| 效果 | 立刻自爆：半径 110 内 `星级 × 30` 伤害 |
| 关键用途 | **死亡不给勇者经验**（勇者只从"他亲手击杀"获得魔气） |
| 代价 | 魔王引爆 CD 2s；每引爆一次给勇者 1 层「饥渴」（攻速 +4%，上限 10 层） |
| 定位 | **应急阀**，不是常规循环 |

**提示义务**（必须做，否则玩家永远想不到）：

1. 首次有魔物血量 <25% 时，屏幕右侧弹一次性提示：「双击他脚下的怪可以引爆 —— 别让他吃掉经验」。
2. 引爆成功后在怪的位置飘字「经验已阻断 +0」。
3. 结算面板显示"引爆次数 ×N"，并给一句评价（"你不怎么用引爆" / "引爆大师"）。
4. 暂停界面的"操作说明"里常驻这一条。

### 3.5 魔王权能（每 30 秒 3 选 1）

触发：每 30 秒（0:30 → 4:30，共 10 次）+ 勇者每升 3 级额外一次。
表现：世界减速到 0.15（不暂停），三张卡错峰飞入。

## 5. 勇者 AI 规格（核心章节）

> 这一章是代码实现的契约。所有参数集中到 `src/content/heroAi.ts`，**只改参数不改逻辑**就能调手感。

### 5.1 设计目标

1. **像人**：会追、会退、会绕、会等，不是直线贴脸木桩。
2. **可读**：任何动作都有前摇与视觉提示，玩家能预判并反制。
3. **可调**：所有阈值外置成配置；所有决策是纯函数，能无渲染跑模拟。

### 5.2 感知层

- **刷新频率 10 Hz**（每 100ms），不是每帧 —— 保证稳定与性能。
- 每次刷新产出一个候选列表，按评分排序，取最高分作为目标。

**目标评分**（分高者优先）：

```
score = 100
      − 距离 / 10                    // 每 100px 扣 1 分：偏好近的
      + (1 − hp%) × 30               // 残血优先
      + 正在攻击我 ? 15 : 0            // 正在打我的人
      + 嘲讽中 ? 100 : 0              // 强制覆盖一切
      + 远程/辅助 ? 8 : 0             // 优先切后排（法师、巫医、毒蜘蛛）
      − 护甲 × 2                      // 不喜欢硬骨头
      + 目标已被我锁定 ? 25 : 0         // 迟滞（见下）
```

**迟滞（防抽搐）**：当前目标的分数需被新目标超过 **25%** 才切换；除非当前目标死亡 / 超出 900 距离 / 有嘲讽。

### 5.3 状态机

```
IDLE ──发现目标──▶ SEEK ──进入攻击距离──▶ ENGAGE
  ▲                  │                      │
  │ 8 秒无目标        │ 目标消失             │ 血量 < 25% 或 技能要求
  │                  ▼                      ▼
  └────── PATROL ◀── SEEK 重新评分      REPOSITION（拉开/绕后）
                                          │ 0.5–2.5 秒后
                                          ▼
                                        RETREAT（撤到安全距离，最多 2.5 秒）
                                          │ 血量回到 55% 或超时
                                          ▼
                                        ENGAGE
血量 < 20% 且第三幕 ──▶ ENRAGE（不再撤退，攻速 +40%，伤害 +20%）
```

| 状态 | 行为要点 |
| --- | --- |
| IDLE | 原地待机，播放呼吸动画 |
| PATROL | 朝最近的"魔物气息点"或随机巡逻点移动，速度 ×0.7 |
| SEEK | 朝目标移动，速度 ×1.0，路径带避障 |
| ENGAGE | 在攻击距离内停下 → 前摇 → 判定 → 后摇；移动只做微调（保持朝向） |
| REPOSITION | 短距离侧移，用于躲 AoE / 找背击位 |
| RETREAT | 远离目标 + 朝场地开阔方向；**不会跑出战斗区域**；最多 2.5 秒 |
| ENRAGE | 无视撤退；攻速 +40%，移速 +25%，技能 CD ×0.7 |

### 5.4 移动（Steering）

- **期望方向** = `normalize(目标点 − 自身位置)`，叠加：
  - **避障力**：对每个石柱/王座台，距离 < 半径+40 时施加反向力（权重 1.5）
  - **绕行力**：避免和其他魔物重叠（权重 0.5，只影响速度不硬推）
- **速度积分**：`v = lerp(v, vTarget, 1 − e^(−k·dt))`，k = 12（约 0.15 秒到目标速度），无瞬移。
- **到达判定**：距离 < 攻击距离 × 0.9 时停止移动（不贴脸抖动）。
- **贴墙滑行**：碰撞后把速度投影到墙的切向，不原地卡死。
- **卡住检测**：0.5 秒位移 < 8px 且期望位移 > 20px → 强制侧向绕行 0.6 秒。
- **边界**：大厅是圆形 + 障碍，超出半径 720 时被拉回。

### 5.5 攻击与技能

**普攻（近战）**

| 阶段 | 时长 | 说明 |
| --- | --- | --- |
| 前摇 windup | 0.18s | 举剑，地面出现扇形预警（淡） |
| 判定 hit | 1 帧 | 扇形 90°、半径 62；命中全部目标 |
| 后摇 recover | 0.16s | 收剑，可被位移打断 |

**剑气（招牌远程，Lv2 起拥有）**

| 项 | 参数 |
| --- | --- |
| 形状 | 直线矩形，长 420、宽 56，穿透 |
| 前摇 | 0.35s（明显蓄力：剑身发光 + 直线预警） |
| 后摇 | 0.3s |
| CD | 6s（受等级与技能影响） |
| 用途 | 清理一排远程/后排；玩家可以通过**分散投放**来减少损失 |

**技能通用规则**

- 每个技能 = `{ id, type: 主动/被动, cd, windup, 评分函数 }`
- 主动技每 0.2 秒评估一次"要不要放"，评分公式：

```
skillScore = 命中目标数 × 12
           + (技能是爆发 ? 目标血量% × 20 : 0)
           + (技能是治疗 ? (1 − 自身hp%) × 60 : 0)
           − 释放成本（0.5s 硬直）
```
  分数 > 20 且 CD 就绪 → 进入**施法锁定**（0.4s 不可打断，除非死亡）。

- **所有 AoE 都有 0.35s 地面预警圈**，玩家可以移动魔王改变投放位置来规避损失。
- 技能释放顺序有优先级表，避免"治疗和剑气同时好了却先放剑气"这类违和。

| 提示 | 表现 |
| --- | --- |

> 原则：**玩家输，必须能复盘出"我哪一步放错了"，而不是"他突然秒了我"。**

### 5.8 可测性

- AI 决策是纯函数：`decide(world, dt) → Intent`，不碰渲染。
- `tools/simulate.mjs` 无渲染跑 1000 局，输出：平均击杀时间、勇者终局等级、引爆使用率、平均在场星数。
- 指标偏差 >15% 就调 §5.6 参数表。
- 确定性：AI 内每秒最多消耗 4 次随机（仅用于巡逻点选择与技能抖动），种子固定可复现。

### 5.9 反模式（明确不做）

| 不做 | 原因 |
| --- | --- |
| 无前摇的瞬发伤害 | 玩家无法应对 = 不公平 |
| 读取玩家下一步输入 | 会显得作弊，且手感怪 |
| 无限风筝（一直跑不打） | 会让玩家觉得"打不到" |
| 每帧重算目标 | 会抽搐，像抽风 |
| 贴脸到像素级精确 | 应该保持 62px 距离，别挤成一团 |
| 技能无视地形 | AoE 应该被石柱遮挡 |

### 8.2 动画：贴图 + 程序化摇摆（不用精灵图）

**核心理由**：AI 出精灵图的一致性极差（同一个角色 8 帧能长成 8 个人），而俯视角小尺寸下，**剪影的摇摆足以表达移动**。

| 动作 | 实现 | 参数 |
| --- | --- | --- |
| 待机 | 呼吸缩放 | `scale.y = 1 + sin(t×2.4)×0.03`，`scale.x` 反向 0.015 |
| 移动 | **左右摇摆 + 上下浮动** | `rotation = sin(t×15)×7°`，`y += sin(t×30)×2.5px` |
| 移动（重甲/大型） | 幅度减小、周期变慢 | `rotation ×0.5`，频率 ×0.6 |
| 攻击前摇 | 蓄力后倾 | `rotation = −8°`，`scale = 1.06/0.96`（0.18s） |
| 攻击命中 | 前冲 + 前倾 | `x += 10px`（朝向），`rotation = +12°`，0.12s 回弹 |
| 受击 | 白闪 + 抖动 | 材质 tint 白 60ms，`x ±4px` 抖动 0.12s |
| 死亡 | 倾倒 + 淡出 + 压扁 | `rotation → 90°`，`alpha → 0`，`scale.y → 0.7`，0.45s |
| 施法 | 微幅上扬 + 光环 | `y −6px`，脚底光环脉冲 |

实现要点：
- 所有角色 = `Container`（锚点在脚底），`Sprite` 挂里面；摇摆只改 Container 的 rotation/scale/position。
- **同一套摇摆曲线，参数化幅度与频率** → 全游戏只有一种"动起来"的语言。
- 攻击/受击用 GSAP timeline 驱动，可被打断且可回滚到待机。
- 这样每个角色只需 **1 张静态贴图**，资产量从 9 组 × N 降到 1 张 × N。
