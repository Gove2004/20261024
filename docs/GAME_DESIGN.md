## 0. 定位

### 0.1 一句话

**你是魔王，你没有身体。你能做的只有一件事：把魔物放下去。**

常规肉鸽你是越杀越强的幸存者；这里你是那个**被讨伐的魔王**——看不见、摸不到、打不了，只能眼睁睁看着自己的造物被一个个砍碎，再放出下一个。

### 0.2 一局是什么样

```
0:00  镜头对准大厅入口，锅巴推门进来
0:03  你在他脚边放下第一只史莱姆（地面亮起法阵）
0:06  他两刀砍碎它，身上亮了一下：锅巴 Lv2，学会了「剑气斩」
0:30  星数上限提升，你 3 选 1 拿到「冷却缩减」
1:20  你在屏幕另一侧放下毒蜘蛛，他开始往那边跑
2:40  他放了一道剑气，把你的三只远程串在一条线上清掉
3:50  你攒到 9 星的巫妖，一发火球砸掉他 1/6 血
4:10  他只剩 900 血，狂化，攻速明显变快
4:38  石像鬼嘲讽拉住他，六只怪围上 —— 他倒下
```

### 0.3 三方关系

| 角色 | 能做什么 | 不能做什么 |
| --- | --- | --- |
| **魔王（玩家）** | 召唤魔物、选权能 | **没有身体**、不能攻击、不会被打、不可被看见 |
| **勇者（AI）** | 远程射击、拉开距离、按等级放技能、升级变强 | 不会攻击魔王（找不到魔王）；**打不到近身战 —— 你没有可点的"引爆"** |
| **魔物（玩家投放）** | 自动索敌、攻击勇者、控制/治疗/召唤 | 无需操作 |

> **为什么去掉引爆**：引爆曾是一键止损的应急阀（双击魔物，清掉它并阻断经验）。
> 实测它同时做了三件事：清怪、断经验、制造爽点 —— 于是玩家 90% 的操作变成"点卡 → 摆 → 双击"，
> 而"摆在哪"这件事被稀释了。现在魔王的唯一动作是**召唤**，唯一决策是**放在哪、什么时候放**。
> 想止损，就只能靠"提前把怪铺在必经之路上"。

**玩家就是魔王，魔王就是玩家。** 屏幕上永远只有锅巴和你的魔物——魔王在哪不重要，他就是镜头之外的那只眼睛。

### 0.4 设计支柱

1. **反向**：成长曲线属于敌人。玩家的核心操作是"控制他在哪、他打谁、他什么时候能打到"。
2. **可读**：勇者每次变强都要看得见（外观 + 播报 + 新技能第一时间展示）。
3. **AI 即手感**：勇者不是木桩，也不是外挂。会追、会退、会连招，但所有动作都有前摇，玩家读得懂、挡得住。

## 1. 场地与角色

### 1.1 场地：魔王殿大厅

| 项 | 数值/说明 |
| --- | --- |
| 世界尺寸 | **2400 × 1600**（设计像素，大于单屏） |
| 视口 | 1280 × 720（16:9），letterbox 适配 |
| 相机 | **始终以锅巴为中心**（跟随他的位置），lerp 0.12，触边夹取 |
| 缩放 | 固定 1.0，不做动态 zoom |
| 地形 | 中央王座台（不可通行，半径 190）、六根可绕行石柱、四角火盆、南面大门 |
| 战斗区域 | **方形大厅** 1640 × 1240（内墙 380,180 → 2020,1420），矩形硬边、贴墙滑动 |

> **为什么是方形**：圆厅的边界处处一样，玩家一平移镜头就分不清自己在大厅的哪一侧；
> 方厅有四个角和四面直墙，方向感是"长出来"的，也更像一个可以绕着打的房间。

**相机规则（重要）**

- 锅巴永远在画面中心附近 —— 玩家看到的战场就是**他正打的战场**。
- 因此**不需要**屏外指示器、不需要小地图：所有敌人都在画面里。
- 大地图的意义：给他**跑动与绕行的空间**（撤退、绕石柱、拉开阵型），而不是"让玩家看更多地方"。

### 1.2 魔王（玩家）

| 项 | 内容 |
| --- | --- |
| 存在形式 | **没有身体、没有位置、不可见**。玩家即魔王。 |
| 能做 | ①召唤魔物 ②每 30 秒选权能 |
| 不能做 | 移动、攻击、被打、被看见 |
| 视觉表达 | 只在召唤时出现：地面浮现的**法阵**（从上方降下的紫黑火光）+ 一小段镜头震动 |

> 这样设计的好处：玩家的注意力 100% 在"放什么、放哪、什么时候放"，没有任何走位负担；也让"手无缚鸡之力"变成真实的游戏体验，而不是设定文字。

### 1.3 勇者：锅巴

| 项 | 内容 |
| --- | --- |
| 职业 | **远程弹弓手**（Y 字木弹弓），全靠射击与技能输出，**没有近战判定** |
| 外观 | 可爱 Q 版平面风：暖黄方脸 + 大眼 + 木弹弓；比魔物更"亮"一档 |
| 行为 | 自动索敌、走到 250px 外站定射击、被贴到 120px 就翻滚后撤、按等级放技能、升级变强 |
| 阶段 | Ⅰ Lv1–4 / Ⅱ Lv5–9 / Ⅲ Lv10+（外观差异见 §8.3） |
| 唯一的敌人 | 你的魔物 |

> **为什么必须纯远程**：近战单位会自己走进怪堆里，玩家能做的只有"堆数量"。
> 远程 + 会拉开距离之后，他成了一个"会躲的火力点"：你必须**封他退路、卡他蓄力窗口**，
> 而不是把怪直接糊在他脸上。

## 2. 核心循环

### 2.1 30 秒节拍（一局 10 拍）

| 拍 | 时间 | 系统 | 玩家 |
| --- | --- | --- | --- |
| 1 | 0:00–0:30 | 教学；星数上限 10 | 学会放置，看到他第一次升级 |
| 2 | 0:30 | **权能 3 选 1**；上限 +5 | 选第一个方向 |
| 3 | 1:00 | 锅巴 Lv3–4，开始放技能 | 学会分散投放，别被剑气串 |
| 4 | 1:30 | 权能；CD 吃紧 | 体会"卡 CD" |
| 5 | 2:00 | Lv5 → **阶段Ⅱ** | 感觉他变强了 |
| 6 | 2:30 | 权能；开始能养出 6★+ 的怪 | 第一次放石像鬼 |
| 7 | 3:00 | Lv7 | 中盘博弈 |
| 8 | 3:30 | 权能；Lv8 | 构筑成型 |
| 9 | 4:00 | Lv9–10 → **阶段Ⅲ** | 进入决战 |
| 10 | 4:30–5:00 | 最后 30 秒，上限接近 60 | 梭哈；**5:00 他活着就判负** |

### 2.2 逐帧循环

```
① 看：他在哪、血多少、我在场几只、哪张卡好了、星数还剩多少
② 放：点卡 → 点画面上的地面（受 CD + 星数上限 + 视野内 三重限制）
③ 打：魔物自动索敌；锅巴走位、攻击、放技能
④ 变：他杀掉的每只魔物都变成魔气 → 升级 → 学新技能 → 更强
⑤ 选：每 30 秒 权能 3 选 1（世界减速到 0.15）
⑥ 判：5:00 或他血空 → 结算
```

### 2.3 胜负

| 条件 | 结果 |
| --- | --- |
| 5:00 前锅巴 HP 归零 | **胜利**（立刻结算，剩余时间计入评分） |
| **倒计时归零而锅巴存活** | **失败**，自动弹出结算：「5 分钟到了，他还站着」 |
| 锅巴升至 Lv15 | **失败**（成长失控，立即结束） |

**倒计时必须明确**：屏幕正上方大字倒计时；10:00 之外另在 **剩 1:00 / 0:10** 时全屏脉冲各一次；归零瞬间画面变灰 + 一声闷响 + 直接进结算，不要留给玩家"是不是还能打"的模糊空间。

## 3. 玩家系统

### 3.1 三条约束（没有经济）

**玩家没有任何货币。** 限制只有三条：

| 约束 | 规则 | 视觉 |
| --- | --- | --- |
| **卡片 CD** | 每张卡独立冷却，就绪才能放 | 卡面环形进度 + 秒数 |
| **星数上限 `X(t)`** | 场上存活魔物的星级总和 ≤ X | 左下星点条 |
| **可见范围** | 只能放在**当前画面内**、且离锅巴 ≥90px、不在障碍物里 | 落点预览（绿/红） |

> 为什么是"画面内"：魔王没有身体，他的"范围"就是他的视线。锅巴在哪，战场就在哪——这条规则让"镜头跟着他"变成玩法，而不是限制。

### 3.2 星级（1–10）

**所有卡牌都在 1–10 星之间，星级就是它的强度与占地。**

| 项 | 规则 |
| --- | --- |
| 初始星级 | 各卡不同（1–4 星），见 §4 |
| 提升方式 | 权能「卡牌升星」每次 +1（最高 10） |
| 属性 | `攻击 = 基数 × 星级`（线性）、`生命 = 基数 × 星级^1.3`（更陡） |
| 体型 | 视觉尺寸随星级放大：`1.0 → 1.55`（1★ → 10★） |
| 占星 | **= 星级**（10★ 占 10 星） |
| CD | `CD = 2.5 + 1.55 × 星级 + 0.05 × 星级²` 秒（1★=4.1s，5★=11.5s，10★=23.0s） |
| 视觉标记 | 卡片角标 `★N`；场上魔物头顶星数小点，N≥7 时描边发光 |

**为什么攻击线性、生命更陡、CD 带二次项**：三者合起来才成立。

- 攻击线性 → 1 只 10★ 与 10 只 1★ 的**输出**等价，玩家的选择不是"数值更大"，而是"要一个大块头，还是一片小东西"。
- 生命 `×星级^1.3` → 大怪才是真的墙（10★ 有 1★ 的 19.9 倍血、而只占 10 星），否则升星只换来更长的 CD，没人愿意养怪。
- CD 带二次项 → "单位星数的召唤吞吐"在 7★ 附近见顶（1★≈0.24、7★≈0.44、10★≈0.43），巨怪变成"高投入、低频次"的承诺，杂兵变成"高频次、可牺牲"的消耗品。

> 这三个数是被 `tools/simulate.mjs` 跑出来的，不是拍脑袋：线性 CD 会让 10★ 的吞吐反而高于 1★，最后所有人都只放巨怪。

| 星数段 | 感觉 |
| --- | --- |
| 1–3★ | 炮灰：便宜、CD 短、占星少 |
| 4–6★ | 主力：能打能扛 |
| 7–8★ | 精英：明显变大 |
| 9–10★ | 巨物：一只就是半支军队，但 CD 接近 20 秒 |

### 3.3 星数上限

| 项 | 规则 |
| --- | --- |
| 曲线 | `X(t) = 10 + 5 × floor(t / 30)`，基础封顶 **60** |
| 权能加成 | 「星数上限」每层 +5，最多 +3 层（峰值 75） |
| 超限 | 卡面变灰 + 提示"星数已满"（已在场的保留） |

示例：0:00→10，1:00→20，2:00→30，3:00→40，4:00→50，5:00→60。

> 60 星 ≈ 6 只 10★，或 15 只 4★，或 60 只 1★——三种完全不同的画面。

### 3.4 没有引爆：所有止损都发生在"提前布置"里

> **这一节是废除记录，写下来是因为它改变了整个游戏的决策重心。**

原型里有过"双击魔物引爆"：范围伤害 + 阻断经验，一键解决"他要吃掉我快死的怪"。
但在 20 局手测里，它把对局变成了**反应游戏**：怪快死了 → 双击 → 继续。玩家不再思考阵型，
因为任何时候都有一次免费的重来。改版后引爆被彻底移除，替换方案是三条：

| 需求 | 替代方案 |
| --- | --- |
| 别让他吃掉快死的怪 | **提前铺第二层**：把新怪放在怪堆与锅巴之间，让他先杀新的 |
| 想清场重来 | **权能「星域扩张」+ 升星**：把资源集中在少数几只高星怪上，而不是铺开 |
| 他贴脸时想救场 | **卡他蓄力**：他每次放技能都会站定 0.12–0.75 秒，这个窗口才是玩家的机会 |

**玩家的操作面就三个数**：卡 CD、星数上限、放哪个位置。少一个按钮，多一层思考。

### 3.5 魔王权能（每 30 秒 3 选 1）

共 10 次（0:30 → 4:30）+ 锅巴每升 3 级额外一次。触发时世界减速到 0.15，3 张卡错峰飞入。

**已实现（M3）：10 条 + 保底升星**

每条都能成为某个流派的支点，且**没有一条是纯数值垃圾**（增幅都在 12% 以上，玩家选得出手）。

| 权能 | 效果 | 定位 |
| --- | --- | --- |
| 尖牙 | 全魔物攻击 +14% | 输出流 |
| 厚壳 | 全魔物生命 +18% | 坦克流 |
| 躁动 | 全魔物攻速 +10% | 尸群/毒流（层数越快越强） |
| 硬皮 | 全魔物护甲 +2 | 抗他远程点射 |
| 冷却缩减 | 全卡 CD −8%（乘算） | 铺场流 |
| 星域扩张 | 星数上限 +5 | 高星流（能让 10★ 提前上场） |
| 更多手牌 | 手牌 +1（最多 8） | 组合流 |
| **诅咒** | 锅巴攻击 −6% | 唯一"反向成长"，压他的输出曲线 |
| **泥泞** | 锅巴移速 −7% | 让他跑不掉，翻滚也甩不开 |
| **封印** | 锅巴技能冷却 +12% | 拖长他的爆发空窗 |
| **卡牌升星** | 指定一张手牌 +1 星（最高 10★） | **每次三选一必出**，玩家的养成通道 |

> 后三条（诅咒 / 泥泞 / 封印）是 M3 新增的方向：前七条改**你的**数值，后三条改**他的**数值。
> 只改自己会变成纯数值爬坡；能改对手，"我在跟一个具体的人博弈"的感觉才成立。

**排期后置**（未实现，别当成已完成）：类型专精（史莱姆自爆、尸群、骨甲…）、结构类（解锁卡牌、剖析弱点）、
遗物（死亡分裂、复活、真实伤害…）。它们的共同问题是需要**新的状态与表现**，
留到 M4 环境特效一起做，避免 M3 摊薄在十几条互不相干的效果上。

> 保底：每次 3 选 1 至少 1 张 A 类或 C 类；**升星选项永远在**（否则玩家没有养成感）。

### 4.1 差异化检查

| 维度 | 卡 |
| --- | --- |
| 消耗他的攻击次数 | 史莱姆、蝙蝠群 |
| 硬抗拖时间 | 骷髅兵、石像鬼 |
| 越位/绕后 | 幽灵、刺客 |
| 远程压制 | 毒蜘蛛、冰霜法师、巫妖 |
| 控场 | 冰霜法师（冻结）、石像鬼（嘲讽） |
| 续航 | 巫医 |
| 爆发 | 自爆虫、刺客 |
| 数量扩张 | 蝙蝠群、骷髅将军 |

> 规则：**同一维度最多 2 张**。新增卡必须先回答"它填哪个空白维度"。

### 4.2 升星的表现

| 星级 | 视觉 |
| --- | --- |
| 1–3★ | 原始尺寸，无特效 |
| 4–6★ | 尺寸 +20%，脚下微光 |
| 7–8★ | 尺寸 +38%，描边发光，头顶星点 |
| 9–10★ | 尺寸 +55%，拖尾粒子 + 地面阴影加深 + 出场时全屏轻震 |

> 升星是**唯一让玩家感到"我的东西在长大"的通道**，必须有明确画面回报。

## 5. 勇者 AI 规格（核心章节）

> 本章是代码实现的契约。所有参数集中在 `src/content/heroAi.ts`，**只改参数不改逻辑**即可调手感。

### 5.1 三条原则

1. **像人**：会追、会退、会绕、会等，不是直线贴脸木桩。
2. **可读**：任何动作都有前摇与视觉提示，玩家能预判并反制。
3. **可调**：全部阈值外置；决策是纯函数，可无渲染跑模拟。

### 5.2 感知层（10 Hz）

每 100ms 刷新一次候选目标，按评分排序取最高：

```
score = 100
      − 距离 / 10                    // 偏好近的
      + (1 − hp%) × 30               // 残血优先
      + 正在攻击我 ? 15 : 0
      + 嘲讽中 ? 100 : 0              // 强制覆盖
      + 远程/辅助 ? 8 : 0             // 优先切后排
      − 护甲 × 2                      // 不喜欢硬骨头
      + 是当前目标 ? 25 : 0           // 迟滞
```

**迟滞**：新目标分数必须超过当前目标 **25%** 才切换，除非当前目标死亡 / 距离 >900 / 有嘲讽。

### 5.3 状态机

```
IDLE ──发现目标──▶ SEEK ──进入攻击距离──▶ ENGAGE
  ▲                  │                      │
  │ 8s 无目标         │ 目标消失             │ 血<25% 或技能要求
  ▼                  ▼                      ▼
PATROL ◀────────── SEEK 重评          REPOSITION（侧移/绕后）
                                          │ 0.5–2.5s
                                          ▼
                                        RETREAT（最多 2.5s）
                                          │ 血回 55% 或超时
                                          ▼
                                        ENGAGE

血<20% 且第三幕 ──▶ ENRAGE（不再撤退；攻速 +40%、移速 +25%、技能 CD ×0.7）
```

| 状态 | 行为 |
| --- | --- |
| IDLE | 原地待机 |
| PATROL | 朝巡逻点移动，速度 ×0.7 |
| SEEK | 朝目标移动，速度 ×1.0，带避障 |
| ENGAGE | 在攻击距离停下 → 前摇 → 判定 → 后摇；只做微调移动 |
| REPOSITION | 短距离侧移，躲 AoE / 找背击位 |
| RETREAT | 远离目标 + 朝开阔处，不越出战斗区，最多 2.5s |
| ENRAGE | 无撤退，攻速/移速提升，技能更频繁 |

### 5.4 移动（Steering）

- **期望方向** = `normalize(目标点 − 自身)`，叠加：
  - **避障力**：距石柱/王座台 < 半径+40 时反向推（权重 1.5）
  - **分离力**：避免与魔物重叠（权重 0.5，只影响速度不硬推）
- **速度积分**：`v = lerp(v, vTarget, 1 − e^(−12·dt))`，约 0.15s 到目标速度，**禁止瞬移**。
- **到达判定**：距离 < 攻击距离 × 0.9 时停（不贴脸抖动）。
- **贴墙滑行**：碰撞后把速度投影到切向，不卡死。
- **卡住检测**：0.5s 内位移 < 8px 且期望位移 > 20px → 强制侧向绕行 0.6s。
- **边界**：超出战斗半径 720 被拉回。

### 5.5 攻击与技能（M3 已实现）

**普攻（远程，唯一输出方式）**

| 阶段 | 时长 | 说明 |
| --- | --- | --- |
| 前摇 | 0.22s | 弹弓拉满 + 一条细瞄准线（地面预警） |
| 判定 | 1 帧 | 单体，射程 **340**；瞄准点偏离 < 0.86 会**射空**（他也会失手） |
| 后摇 | 0.16s | |
| 伤害 | `atk × 60/(60+护甲)` | 百分比减伤，而不是"减到 4 点" |

> **百分比减伤是必须的**：改版前是 `atk − 护甲`，遇到 22 护甲的高星怪时
> 他 26 点攻击只能打出 **4 点**（几乎无敌墙）。改成 `×60/(60+护甲)` 后，
> 护甲仍然值钱（22 护甲 = 减伤 27%），但不会让高星怪变成免伤铁块。

**7 个主动技能（每个都有强制前摇，玩家看得见）**

| 技能 | 前摇 | CD | 触发条件 | 效果 |
| --- | --- | --- | --- | --- |
| 射击 | 0.22 | 0.9 | 有目标 | 单体 340 射程 |
| 散射 | 0.3 | 7 | 锥形内 ≥2 只 | 5 发扇形，每发 0.62 倍伤害 |
| 剑气 | 0.35 | 6 | 一条直线上 ≥2 只 | 460×56 穿透 |
| 爆米花弹 | 0.6 | 11 | 某点 120px 内 ≥3 只 | 0.6s 预警后 2.6 倍 AoE |
| 蓄力重击 | 0.75 | 10 | 有目标 | 3.2 倍单体，420 射程 |
| 干粮 | 0.35 | 14 | 生命 <38% | 回 12% 最大生命 |
| 翻滚 | 0.12 | 8 | 被贴到 120px 内 | 后撤 130px + **0.35s 无敌** |

**优先级表（固定，不随机）**：`干粮 → 翻滚 → 蓄力重击 → 爆米花弹 → 散射 → 剑气 → 射击`

> 优先级必须固定。玩家要在 3 秒内学会"他什么时候会滚、什么时候会吃"，随机优先级等于没规律。
> 顺序也是"活命 > 打疼"：血低先吃，被贴先滚，然后才是输出手段。

**蓄力时站定**：放技能期间他不能移动。这是玩家唯一稳定的"贴上去"窗口 ——
没有这条，远程单位会在测试里全程不掉血（8 局平均剩 87% 血，玩家完全没有紧张感）。

**14 条被动（每次升级随机 1 条）**

| 被动 | 效果 | 被动 | 效果 |
| --- | --- | --- | --- |
| 硬弓 | 攻击 +8% | 快弦 | 攻速 +10% |
| 轻甲 | 最大生命 +10% | 疾行 | 移速 +6% |
| 长臂 | 射程 +10% | 贯穿 | 普攻多穿 1 个 |
| 老练 | 技能 CD −8% | 饱餐 | 击杀回 4% 生命 |
| 聚气 | 剑气伤害 +15% | 重锤 | 蓄力重击 +20% |
| 散弹 | 散射多 1 发 | 铁骨 | 受伤 −6% |
| 巧手 | 技能 CD −8% | 蛮力 | 全部技能伤害 +6% |

> 被动是"看得见的成长"：每次升级都会在屏幕中上方播报「锅巴 Lv.N / 获得被动：X」。
> 没有这条播报，玩家只会觉得"怪突然打不动了"，而不知道自己错过了什么。

### 5.7 可读性

| 提示 | 表现 |
| --- | --- |
| 当前意图 | 头顶图标：⚔ 追击 / ◐ 蓄力 / ↩ 撤退（0.3s 更新） |
| 当前目标 | 极淡连线（可关） |
| 技能前摇 | 每种技能一条专属地面预警（瞄准线 / 扇形 / 剑气带 / 红圈 / 治疗环 / 翻滚环） |
| 阶段变化 | 全屏白闪 + 色调变化 + 播报「锅巴 进入 阶段Ⅱ」 |
| 升级 | 中屏横幅「锅巴 Lv.N + 获得被动：X」 |

> 原则：**输了必须能复盘出"我哪一步放错了"，而不是"他突然秒了我"。**

### 5.8 可测性

- `decide(world, dt) → Intent` 纯函数，不碰渲染。
- `tools/simulate.mjs` 跑 N 局，输出：胜负、终局等级、击杀数、峰值星、剩余血量。
- 偏差 >15% 调 §5.6。
- 确定性：AI 每秒最多消耗 4 次随机（巡逻点、技能抖动），种子固定。

### 5.9 反模式

| 不做 | 原因 |
| --- | --- |
| 无前摇瞬发伤害 | 玩家无法应对 |
| 读取玩家下一步输入 | 显得作弊 |
| 无限风筝 | 玩家会觉得"打不到" |
| 每帧重算目标 | 抽搐 |
| 贴到像素级重叠 | 应保持 62px，别挤成一团 |
| AoE 无视石柱 | 破坏地形价值 |

## 6. 勇者成长

### 6.1 属性

| 属性 | 初始 | 每级 | 上限 |
| --- | --- | --- | --- |
| HP | 12000 | +600 | — |
| 攻击 | 26 | +7.0 | — |
| 攻速 | 1.1/s | +0.018 | 2.4/s |
| 移速 | 108 | +2.2 | 152 |
| 护甲 | 0 | +1（%减伤） | — |
| 暴击 | 5% | 仅强化 | — |

> **为什么是万级血**：玩家的星数预算是 10–60，一只 1★ 史莱姆约 7 dps，场面铺满 20–30 星时对他是 100+ dps。
> 2600 血之类的数字撑不住 5 分钟，实战一跑就是 90 秒暴毙（这是第一版实测结果）。
> 护甲走**百分比减免**而不是减法：减法会让"杂兵 vs 高护甲"直接塌成 1 点伤害。

### 6.2 经验

- 亲手击杀 → 魔气：`星级 × 8`（1★=8，10★=80）。
- `XP_need(L) = 60 + 45 × (L − 1)`；Lv1→2 需 60，Lv10→11 需 465。
- 每级 1 条随机强化（可见播报）；每 3 级 1 条强力强化（必带视觉表现）。

### 6.3 技能池（7 主动 + 14 被动，已实现）

**主动（7）** —— 完整参数见 §5.5，这里是设计意图

| 技能 | 设计意图 |
| --- | --- |
| 射击 | 基线输出，逼玩家"别让他站桩" |
| 散射 | 惩罚**抱团放置** |
| 剑气 | 惩罚**一条直线摆放** |
| 爆米花弹 | 惩罚**扎堆堆叠**（落点前 0.6s 有圈，能挪走） |
| 蓄力重击 | 惩罚**单只高星怪硬顶** |
| 干粮 | 惩罚"只打不控"，拖长战斗他就回血 |
| 翻滚 | 惩罚"贴脸围杀"，必须靠封退路而不是贴脸 |

> 七条技能各自对应一种"错误的摆法"。玩家的学习曲线就是逐个踩坑，
> 而不是去记一堆数值 —— 这也符合评委"一看就会玩"的取向。

**被动（14）**

硬弓 +8% 攻击 / 快弦 +10% 攻速 / 轻甲 +10% 生命 / 疾行 +6% 移速 / 长臂 +10% 射程 /
贯穿 +1 穿透 / 老练 −8% CD / 饱餐 击杀回 4% / 聚气 +15% 剑气 / 重锤 +20% 蓄力 /
散弹 +1 散射发数 / 铁骨 −6% 受伤 / 巧手 −8% CD / 蛮力 +6% 全技能

> 全部是**小幅但可见**的成长，叠加 12 级后他能扛住任何单一流派；
> 这是"玩家必须换着打法"的原因，也是每局不一样的原因。

### 7.3 公式

```
星数上限   X(t) = 10 + 5 × floor(t/30)，基准封顶 60
卡牌 CD    CD = (2.5 + 1.55×星 + 0.05×星²) × 0.92^(冷却缩减层数)
卡牌属性   攻击 = 基数ATK × 星 × (1 + 0.14 × 攻击强化层)
           生命 = 基数HP × 星^1.3 × (1 + 0.18 × 生命强化层)
升级经验   XP_need(L) = 60 + 45 × (L − 1)
击杀所得   魔气 = 星级 × 8
锅巴 HP    HP(L) = 12000 + 600 × (L − 1)
锅巴护甲   ARM(L) = L − 1 ，减伤 = ARM / (ARM + 60)
锅巴攻击   ATK(L) = 26 + 7.0 × (L − 1)，对魔物结算 = ATK × 60/(60+护甲)
锅巴移速   SPD(L) = min(108 + 2.2 × (L − 1), 152)
魔物伤害   对锅巴 = 魔物攻击 × (1 + 0.05 × 星级) × 2.2
```

| 倒计时 0:10 | 屏幕边缘红色脉冲 |

粒子同屏 ≤600，对象池，热路径零分配。

### 8.5 镜头

## 10. 技术

- TypeScript + Vite + PixiJS 8，2D。
- 相机 = `world.position` 反向平移（不动 `stage.scale`，避免 UI 跟着缩放）。
- 视锥剔除：只渲染视野 +200px 内的实体；背景一张 2400×1600 大图（1 Draw call）。
- 分层：`core → ecs → gameplay → render → ui → app`。
- 种子化 PRNG；AI 纯函数化以便模拟。
- 预算：实体 ≤200、粒子 ≤600、Draw call ≤120、首屏 ≤3MB。
