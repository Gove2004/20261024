## 0. 定位与前提

### 0.1 一句话定位

**《吸血鬼幸存者》的画面感 + 《土豆兄弟》的构筑节奏 + 立场完全倒转。**

经典肉鸽：你是那个越杀越强的幸存者，怪物是刷出来的饲料。
本作：**魔物是你派出去的，越强的是对面那个勇者，你是那个坐在王座上的魔王。**

### 0.2 玩家实际在玩什么

| 玩家以为自己在玩 | 实际上在玩 |
| --- | --- |
| 摆魔物打勇者 | **养虎**：控制"给他多少魔气" |
| 攒资源升级 | 在"让他变强换战功"与"别让他强到砍死我"之间走钢丝 |
| 塔防 | 反向塔防：塔是我方的、兵是对面的、还会打野升级 |

### 0.4 三条必须成立的设计支柱

1. **反向**：变强的是敌人，玩家的工作是"管理敌人的成长曲线"。做成普通塔防即失败。
2. **可读**：勇者每一次变强都必须**肉眼可见**（烧穿、变色、学会新招、播报）。
3. **再来一局**：结算必须留下一个"如果我刚才少送两只魔物"的念头。

## 1. 世界观与角色

### 1.1 背景故事

魔王城第九层，王座底下堆着三百年来挑战者的骨头。

今天来的是个瘦得不像话的勇者，背着一口凹了边的铁锅当盾牌，脸上有一片烧疤。城里的魔物叫他「锅巴」——因为这人**又硬又难啃，烧过一遍还没死**。

魔王本可以一巴掌拍死他。

……但你决定先看看他能长成什么样。

**玩法即叙事**：你派魔物上去，他一只只砍穿、吸走魔气、越来越强。你把一个杂鱼养成屠龙者，再亲手折断他——这就是魔王这个身份会干的事。

### 1.2 玩家身份：魔王

| 项 | 内容 |
| --- | --- |
| 称呼 | 魔王（玩家） |
| 视角 | 坐在王座上俯视大厅，第 5 分钟前不用起身 |
| 能力表现 | 抬手召唤魔物、打响指引爆魔物（献祭）、降下权能（强化） |
| 失败条件 | 勇者撑到 5:00 仍存活 → 他踏上王座台阶，你成为第 302 具骨头 |
| 胜利条件 | 5:00 内把他打碎 |

### 1.3 主角：锅巴（勇者）

> **重要**：锅巴是**名字 / 绰号**，不是一块锅巴（食物）造型。视觉上他是一个人。

| 项 | 内容 |
| --- | --- |
| 本名 | 无人记得，登记簿上写的是"锅巴" |
| 外形 | 十六七岁，瘦，破旧皮甲，卷曲烧焦的黑发，左颊一片烫伤疤；**背着一口凹了边的铁锅当盾牌**，右手短剑 |
| 记忆点 | 那口锅。被砍中时用锅挡；狂化时锅沿裂开、火星从锅里漏出来；死亡时锅先碎 |
| 为什么叫锅巴 | 三年前被龙焰烧过一次没死，脸上的疤与龟裂焦壳一样，"锅巴"就成了绰号 |
| 声音 | 铁锅被敲的闷响、粗喘、短促的怒吼 |
| 口头禅 | 「锅巴，够硬就行。」 |

### 1.4 三个形态（对应三个阶段）

| 阶段 | 等级 | 形态 | 视觉变化 |
| --- | --- | --- | --- |
| Ⅰ 少年 | Lv1–4 | 干净皮甲、锅完好 | 亮、瘦、动作轻 |
| Ⅱ 灰烬 | Lv5–9 | 皮甲焦黑、疤痕蔓延、锅沿出现裂口 | 暗、身上冒细烟、眼睛泛橙光 |
| Ⅲ 焚身 | Lv10+ | 全身龟裂透出熔岩光、铁锅裂成三瓣仍在用 | 高亮轮廓、火星拖尾、步伐带震 |

> 关键：**他不是"变大"，而是"烧穿"**。同一个人的三个阶段，视觉张力比换模型更强。

## 2. 核心循环

### 2.1 25 秒节拍

```
① 看：他在哪、血多少、场上还剩几星、他下一级还差多少魔气
② 选：从 4–6 张手牌里挑一张（费用 / 星级 / 位置）
③ 放：拖到大厅地面，魔物自动开始攻击
④ 收：他杀掉魔物 → 吸走魔气 → 升级 → 播报「锅巴 学会了 旋风斩」→ 他更强
⑤ 判：继续送？还是先引爆止损？
   └─ 每 25 秒 / 他每升 3 级 → 弹「魔王权能」3 选 1（你的成长回合）
```

### 2.2 一局 5 分钟的三幕

| 幕 | 时间 | 主题 | 玩家该有的感受 |
| --- | --- | --- | --- |
| 第一幕 养虎 | 0:00–1:40 | 学习 + 第一次"我把他养大了" | "诶？他变强了" |
| 第二幕 博弈 | 1:40–3:20 | 星数上限放开、卡牌升星、他学会大招 | "再送会不会翻车" |
| 第三幕 崩坏 | 3:20–5:00 | 他血线低 → 狂化；玩家梭哈 | "快！快！快！" |

### 2.3 胜负

- **胜利**：5:00 之前把勇者 HP 打到 0。
- **失败**：5:00 到时他仍存活（"他踏上台阶，你听见骨头被踢开的声音"）。
- **特殊失败**：他升到 Lv 15（"他把自己烧成了第二个魔王"）→ 立即结束。
- 失败不是惩罚，是钩子：结算面板明确写"再造成 87 点伤害就赢了"。

## 3. 玩法系统

### 3.1 场地与视角

- 2D 俯视角，单屏，不滚动。
- 场地：**魔王殿**，圆形大厅（直径 ≈ 900 设计像素），中央是王座台的边缘，外圈是熔岩沟。
- 三个环带（视觉提示，有轻机制）：
  - 内环（0–140）：**王座台前**，魔物 +10% 攻速（"守家门"）
  - 中环：常规战场
  - 外环：魔物移速 +15%（"绕后"）
- 勇者从大厅正门（下方）登场，全程在厅内活动；第三幕他会往王座方向压。

### 3.2 资源：魔魂

| 项 | 数值 |
| --- | --- |
| 名称 | 魔魂（Soul） |
| 初始 | 20 |
| 上限 | 100（权能可到 160） |
| 回复 | 8 / 秒（权能可到 22 / 秒） |
| 额外来源 | 魔物死亡返还 50% 费用；献祭返还 60% |
| UI | 大厅下方的发光魂条 + 数字 |

**设计意图**：魔魂是"手速"资源，回复速度决定"你能多快把魔物送上去"，是权能争夺的第一优先级。

### 3.3 星级预算（核心约束）

> 场上所有存活魔物的**星级总和**不能超过上限 `X(t)`。

| 项 | 规则 |
| --- | --- |
| 基础曲线 | `X(t) = 3 + floor(t / 25)`，t 秒，基础封顶 15 |
| 权能上限 | 「星域扩张」每层 +2，最多 +6（峰值 21） |
| 表现 | 大厅外圈一圈星点，亮起数量 = 当前占用 |
| 超限 | 卡片变灰 + 提示"星域已满"，新魔物放不下（已放的不受影响） |

示例：0s→3，1:00→5，2:00→7，3:00→10，4:00→12，5:00→15。

**为什么用星级而不是数量**：让玩家在"很多弱怪"和"一只强怪"之间做真实选择——两者对勇者的意义完全不同（弱怪 = 快速魔气饲料；强怪 = 高价值目标 + 更长的拖延）。

#### 3.4.3 手牌

- 手牌位 4（权能可到 6），开局固定 4 张 ★ 卡。
- 卡牌升星：权能抽到该族卡 → 该卡永久升 1 星（仅本局）。
- 所有卡**无冷却**，唯一限制是魔魂与星级预算。

#### 3.4.4 献祭（关键止损）

| 项 | 内容 |
| --- | --- |
| 触发 | 双击场上魔物 / 长按 0.4 秒 / 右键 |
| 效果 | 立刻引爆：半径 110 内造成 `星级 × 28` 伤害；返还 60% 费用 |
| 代价 | **不给勇者魔气**（这是重点——你在断他的供养） |
| 副作用 | 每献祭一次，勇者获得 1 层「饥饿」（攻速 +4%，最多 10 层） |
| 教学 | 第一次出现"他快升级了"时提示：「引爆能断他供养，但会让他更饿」 |

**设计意图**：给玩家"反喂"手段，让"送多少"变成真策略，而不是被动挨打。

### 3.5 勇者：锅巴（AI）

#### 3.5.1 基础属性

| 属性 | 初始 | 每级成长 | 说明 |
| --- | --- | --- | --- |
| HP | 520 | +55 | 血条在顶部 + 头顶双显示 |

| 攻速 | 1.1 次/秒 | +0.018 | |
| 移速 | 108 px/s | +2.2（上限 +44） | |
| 护甲 | 0 | — | 仅来自强化 |
| 暴击率 | 5% | — | 仅来自强化 |

#### 3.5.2 经验与等级

- 来源：击杀玩家魔物（★=20，★★=45，★★★=100）。
- 升级需求：`XP_need(L → L+1) = 50 + 35 × (L − 1)`
  - Lv1→2：50　Lv2→3：85　Lv5→6：190　Lv10→11：365
- 累计到 Lv10 约 1710 魔气 ≈ 85 只 ★ 魔物。
- **每升 1 级必得 1 条强化**（权重随机，玩家可见播报）。
- 每 3 级额外获得 1 条「标志性强化」（必定强力且视觉化：旋风斩 / 冲锋 / 焚身）。

#### 3.5.3 AI 状态机

```
   ┌─────────┐  有魔物在射程内   ┌──────────┐
   │  SEEK   │──────────────────▶│  ATTACK  │
   │ 追最近怪 │◀──────────────────│ 挥剑/技能 │
   └─────────┘    目标死亡        └──────────┘
     │  │                              │
     │  │ 血<25% 且 还有治疗           │
     │  ▼                              │
     │ ┌─────────┐  回到 60%           │
     │ │ RETREAT │─────────────────────┘
     │ └─────────┘
     │ 血<20% 且 第三幕
     ▼
   ┌─────────┐  血回 45% 以上
   │ ENRAGE  │──▶ 伤害 +60%，移速 +40%，不再后退
   └─────────┘
```

- 目标选择：最近魔物；有「嘲讽」优先；3 秒无目标则朝大厅中心移动。
- 技能释放：独立 CD，按"目标数 / 血量 / 距离"打分决定时机——追求**好看且公平**，不做读指令级闪避。
- 公平性：玩家永远能通过位置与卡组控制节奏。

### 3.6 玩家：魔王权能

#### 3.6.1 触发节奏

### 5.7 音频：全部程序生成

> **不引入任何音频文件（0 KB 音频资源）**，全部用 WebAudio 实时合成。
> 理由：① 零加载、零解码、无版权问题；② 能随游戏状态实时改变（他越强，音乐越凶）；③ 不依赖外部音乐模型（此前 Suno 端点返回 403，直接绕开）。

#### 5.7.1 音乐

| 项 | 设计 |
| --- | --- |
| 形式 | 步进音序器，120 BPM，16 步 × 8 小节循环 |
| 调性 | D 弗里吉亚（D–E♭–F–G–A–B♭–C），天然"邪恶/奇幻"听感 |
| 和声 | i–♭VI–♭III–♭VII 循环 |
| 音色 | drone（锯齿 + 低通）、bass（方波 + 短包络）、pad（三音锯波 + 慢起音 + 混响）、鼓（底鼓=正弦下滑 / 军鼓=噪声带通 / 镲=高通噪声）、旋律（三角波 + 延迟） |
| 动态分层 | 第一幕：drone + bass；第二幕：+ pad + 鼓；第三幕：+ 旋律 + 失真 + 提速 8% |
| 危机感 | 勇者血 <30% 时叠加心跳（0.9 秒两次低频脉冲）+ BGM 低通关闭（变亮变刺耳） |
| 结算 | 胜利：同调性上行琶音；失败：下行小二度 + 长混响 |

#### 5.7.2 音效配方（合成，非采样）

| 音效 | 合成方式 |
| --- | --- |
| 魔物放置 | 正弦 220→440Hz 上滑 120ms + 短混响 |
| 命中 | 白噪声 40ms + 带通 1.2kHz + 快衰减，音高随机 ±8% |
| 暴击 | 方波 400→120Hz 下滑 + 失真 + 噪声叠加 |
| 魔物死亡 | 噪声 + 低通扫频 2k→200Hz，240ms |
| 勇者升级 | 大三和弦琶音（3 音）+ 上升扫频 + 混响 1.2s |
| 献祭 | 低频 80Hz 下坠 400ms + 失真 + 噪声爆 |
| 铁锅格挡 | 三角波 180Hz + 金属泛音（×2.7、×5.4）+ 短衰减 |
| UI 点击 | 方波 1kHz 8ms |
| 播报 | 双音上行（C5→G5） |

#### 5.7.3 混音与性能

- 总线：`Master → Compressor → destination`；`BGM` / `SFX` / `UI` 三条子总线。
- 命中时对 BGM 侧链压低 3dB，200ms 恢复（让打击感"顶出来"）。
- 同时发声 ≤40 个；振荡器用完即 `disconnect()`；同一音效 40ms 内合并，避免爆音。
- 首次 `pointerdown` 再 `resume()` AudioContext（浏览器自动播放策略）。
- 设置面板提供「音乐 / 音效」两条音量滑杆，默认 70% / 85%。

## 6. 技术实现要点（摘要）

完整选型见 `docs/TECH_STACK.md`。

- **栈**：TypeScript + Vite + PixiJS 8，纯 2D，无 3D。
- **分层**：`core`（循环/事件/随机）→ `ecs` → `gameplay`（战斗/卡牌/权能/AI）→ `render`（渲染/粒子/镜头）→ `ui`（DOM）→ `app`（装配）。
- **确定性**：所有随机走种子化 PRNG（`mulberry32`），支持"每日魔殿"与回放/模拟。
- **无渲染模拟**：`tools/simulate.mjs` 跑 1000 局校准 §4.2 曲线。
- **预算**：实体 ≤400，粒子 ≤600，Draw call ≤120，首屏资源 ≤3MB（无音频资源）。
