## 1. 一句话介绍（可直接粘）

> **你是深渊，不是勇者。** 在一间深色魔王殿里，你把史莱姆、幽灵、骷髅一层层摆到来讨伐你的小勇者"锅巴"面前——他越打越强，你越摆越凶，五分钟后只有一个活着走出去。

## 2. 三段式介绍（可粘）

**玩法反转。** 所有肉鸽都在教你"扮演英雄杀出去"，这个游戏让你坐在魔王的位置上：你没有身体、不能攻击、也不能移动，你**唯一能做的事就是召唤**。放什么、放哪、什么时候放，就是全部的决策。

**他会成长，你也会。** 锅巴（AI 勇者）会自己走位、远程放风筝、被贴脸就翻滚；每升一级，他就从 7 个主动技能（散射 / 剑气 / 爆米花 / 重弹 / 治疗 / 翻滚 / 平射）里挑一个用，并随机叠一条被动。你这边靠击杀积累星数，用更高的星级召唤更凶的魔物，升级时从 10 条权能里选 3 条。

**五分钟后一定有人倒下。** 时间到锅巴还活着就是你输。没有存档、没有重开惩罚，输了立刻想"下一把换个摆法"。

## 3. 操作（评委 10 秒上手）

1. 点下方的怪物卡 → 点地面摆放（消耗星数，星数随击杀增长）
2. 右键 / Esc 取消选择；`Space` 暂停；`M` 静音
3. 手机：同样点卡 → 点地面，手牌可左右滑

**目标**：在 5 分钟倒计时结束前把锅巴打死。

## 5. 技术亮点（用于技术向评委）

- **零音频资源**：BGM 与全部音效由 WebAudio 实时合成（120BPM / D 弗里几亚，随剩余时间收紧），仓库里没有任何 mp3/ogg/wav
- **美术 100% 模型生成**：19 张贴图（12 怪 + 主角双形态 + 王座 + 4 环境），提示词 → 生成 → 抠图 → 评审全自动脚本化
- **确定性**：种子化 RNG + 固定 1/60 步长，同一随机种子能重放整局（冒烟测试靠这个做定量断言）
- **可验证**：19 条规则单测 + 26 项无头浏览器端到端冒烟 + 音频探针 + 移动端三视口布局断言
- **体量**：`dist` 约 1.8MB（含全部贴图），纯静态，无后端

## 7. 部署（维护者操作）

构建产物已推到 `gh-pages` 分支（相对路径，子目录部署也能跑）：

```powershell
npm run build
# 把 dist/ 内容推到 gh-pages（临时目录，不动 main 的工作区）
```

开启 Pages：仓库 **Settings → Pages → Source: Deploy from a branch → Branch: `gh-pages` / `(root)` → Save**，
约 1 分钟后 https://gove2004.github.io/20261024/ 可访问。

## 8. 已知取舍（诚实写出来，比藏起来好）

- 只有一张地图、一种勇者；构筑差异来自卡池/权能/技能抽取，不来自地图
- 难度曲线靠一个"笨蛋 AI"调平衡（8 局模拟 2 胜，终局血量中位数 50%）——高手会明显更轻松
- 没有存档与排行榜；一局 5 分钟，重开成本几乎为零
