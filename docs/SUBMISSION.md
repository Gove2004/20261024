## 2. 作品简介（124 字 · **终选文案**，可直接粘）

你是魔王。你连身体都没有，所以画面上看不到你：镜头永远跟着来讨伐你的勇者「锅巴」。你能做的只有一件事——在他必经之路上，提前把魔物摆好。他杀你的怪会变强，你每 30 秒拿一条「七宗罪」权能也会让你的怪变强。五分钟内把他留下，或者看着他推平你的王座。

## 3. 三段式介绍（可粘）

**玩法反转。** 所有肉鸽都在教你"扮演英雄杀出去"，这个游戏让你坐在魔王的位置上：你没有身体、不能攻击、不能移动，你**唯一能做的事就是召唤**。放什么、放哪、什么时候放，就是全部的决策。

**双向成长。** 一局 5 分钟切成 10 个 30 秒节拍：摆怪 + 收权能。他杀得越多越强（7 技能 / 7 条美德天赋，重复获得会升级 / 追击-撤退-蓄力-暴怒四态 AI）；你每 30 秒三选一「七宗罪」（暴食、色欲、贪婪……改护甲、减伤、攻速、星数上限）。两边曲线谁先拐起来，这局就归谁。

**看得见的压力。** 五张卡是五种走位——史莱姆堵路、蝙蝠群穿行、哥布林远程消耗、石像鬼卡弹道、巨大蜘蛛吐丝近咬还生小蜘蛛。星数上限随时间上涨，牌面越铺越大；没有经济、没有抽卡，所有止损都发生在开打之前。

## 4. 详细介绍（约 450 字）

**反向视角。** 玩家就是魔王，而魔王没有身体。所以镜头永远跟着锅巴，玩家是在**被讨伐方的视角**里做决策——他在哪，你的视野就在哪；他走出画面，你就看不见他。这是这类游戏里最反直觉的一条：你控制的不是一个人，是一群怪。

**30 秒一个节拍，一局 10 拍。** 每个节拍玩家做两件事：摆怪、收权能。魔物 5 张、星级 1–10、放得越多这张卡越强；未解锁的卡一开始就在手牌里，显示倒计时、点不动。锅巴这边有 7 个主动技能、7 条美德天赋、10Hz 感知与目标迟滞，被贴脸会翻滚，被围会拉扯，残血会更谨慎——他不是一条直线冲脸的靶子。

**记忆点。** ① 看不见的魔王：玩家控制的是一群怪，不是一个人；② 相机跟着敌人；③ 没有经济系统、没有抽卡，只有"提前布置"这一件事。

**技术与美术。** TypeScript(strict) + PixiJS 8，固定步长 1/60 逻辑，DOM overlay 做 HUD，零第三方 UI 库。美术全部由图像模型生成，统一暗紫血红调。**音乐音效 100% 用 WebAudio 现场合成，没有一个音频文件**，加载体积为零。交付物是一个静态站点，点开链接就能玩，不用装、不用登录，手机横竖屏都能开。

**完成度。** 不是 Demo：完整 5 分钟一局的胜负判定、结算数据、再来一局闭环；新手教程进局先讲一遍（可关）；冒烟测试 70/70 通过，线上探针 LIVE PASS。

## 5. 操作说明

| 操作 | 说明 |
| --- | --- |
| 点手牌 | 选卡（未解锁的卡显示倒计时，点不动） |
| 点地面 | 在当前画面内召唤；连点可连续放，充能层数用光才取消选中 |
| 每 30 秒 | 三选一「七宗罪」权能，世界暂停 |
| 左上「查看详情」 | 展开锅巴的属性 / 技能 / 已获得美德 |
| 目标 | 5 分钟内让他倒下；倒计时归零他还活着，就是你输 |

## 6. 对照四条评判
